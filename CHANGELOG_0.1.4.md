# Klaso Mobile v0.1.4

The interface uses less space so more school information fits on screen.

- Shorter header and navigation bar, narrower phone margins, and tighter section spacing.
- More compact grade, behavior, attendance, message, account and settings cards.
- Teacher and room share a wrapping line in the timetable; all lesson details remain available.
- Smaller summary icons, headings and profile avatar, with Android 48 px and iOS preview 44 px button heights retained.
- Android Material You, iPhone Liquid Glass, English/Polish, light/dark themes, safe areas and tablet layouts remain supported.
- The browser About test reads the package version instead of hardcoding an older release.

Android version: 0.1.4 / version code 5. ARM64, Android 7 / API 24 or later. The development APK uses the same debug signing certificate as v0.1.3. SHA-256 is provided in the release checksum asset.

See [validation results](MOBILE_VALIDATION.md) for automated checks and remaining device checks.
